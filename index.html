Mind maps and flowcharts that stay in your browser, with an API any AI can use. API reference · Source

TabAdd a child of the selected node
EnterAdd a sibling (a child when the root is selected)
Space / F2 / double-clickEdit text (Enter saves, Shift+Enter new line, Esc cancels)
DeleteDelete the selection (nodes with their branches, or a link)
← → ↑ ↓Move the selection between nodes
Shift+clickSelect several nodes; L links two selected nodes
CCollapse or expand a branch
GSnap to grid on/off (size in the Map tab; applies to free placement)
Ctrl+Z / Ctrl+YUndo / redo
Ctrl+DDuplicate the selected branch
Ctrl+C / Ctrl+VCopy the selected branch as an outline / paste an outline, JSON map or operations
Ctrl+FSearch; Enter jumps to the next match
F, +, −Fit, zoom in, zoom out
Drag a node onto anotherMove it (and its branch) under that node
Drag a node's dot onto anotherDraw a link with an arrow; double-click the link to label it
Double-click the canvasAdd a floating node (handy for flowcharts)
