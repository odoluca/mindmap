How it works

Mindmap is a static site. Maps are stored in your browser (IndexedDB) and never leave it unless you export them. There is no server, so there is no HTTP endpoint; instead the page itself is the API. Everything the editor does goes through one set of operations, and anything that can reach those operations has the same editing power as you. Three transports exist:

TransportWho it is forSetup
PasteAny AI, including chat assistants that cannot browseNone
LinksAny AI that can write a URL, bookmarks, other appsNone
window.mindmapBrowser-driving agents (Claude in Chrome, Playwright, extensions), the devtools consoleNone; the object is always present

Every change records an author. Nodes added by someone other than you get a small badge, and the Log tab shows who did what, so AI edits are visible and reversible (undo works on them too). Notes are comments attached to a node or the map, kept separate from node text so an agent can annotate without rewriting your words.

1. Paste round trip

  1. In the editor choose Export ▾ Copy JSON (complete) or Copy outline (compact markdown) and give it to the AI.
  2. Ask for a change. The AI replies with an outline, an operations array, or an edited map JSON.
  3. Select the node the material belongs under, then press Ctrl+V on the canvas, or paste into the AI / API panel and click Apply (there you can also set the author name).

Pasted outlines are added under the selected node (or the root). Operation arrays are applied to the open map. A full map JSON is imported as a new map.

2. Link commands

Open a URL of the form https://odoluca.github.io/mindmap/#command=value. One command per link. The value is either URL-encoded text/JSON or base64url prefixed with b64: (use mindmap.encodeForUrl(value) or mindmap.linkFor('ops', ops) to build one). The hash never reaches a server. After running, the command is removed from the address bar.

CommandEffect
#ops=[…]Apply an operations array to the open map (the last-used map is opened first).
#outline=…Create a new map from a markdown outline (its first heading or item becomes the name).
#import={…}Import a full map JSON as a new map and open it.
#open=<id>Open the map with that id.
#cmd={…}General form: {"ops":[…], "author":"claude"}, {"outline":"…", "parent":"Node text", "append":true}, {"open":"id"}, {"map":{…}}. Keys can be combined; open runs first.

Map JSON

{
  "app": "mindmap", "version": 1,
  "id": "m3k1…", "name": "Project plan", "kind": "mindmap",
  "createdAt": "2026-11-09T10:00:00.000Z", "updatedAt": "…",
  "settings": { "layout": "mindmap", "edgeStyle": "curved", "showAuthors": true },
  "view": { "x": 0, "y": 0, "scale": 1 },
  "nodes": [
    { "id": "n1", "text": "Project plan", "notes": "", "shape": "rounded", "color": "default",
      "parent": null, "x": 0, "y": 0, "w": null, "h": null, "collapsed": false, "tags": [],
      "author": "user", "createdAt": "…", "updatedAt": "…" },
    { "id": "n2", "text": "Phase 1", "parent": "n1", "color": "blue", … }
  ],
  "edges": [ { "id": "e1", "from": "n2", "to": "n5", "label": "blocks", "directed": true, "style": null, "color": "default", "author": "user", "createdAt": "…" } ],
  "notes": [ { "id": "c1", "target": "n2", "text": "Agreed on Monday", "author": "claude", "createdAt": "…" } ],
  "log":   [ { "at": "…", "author": "claude", "op": "addNote", "id": "c1", "summary": "Note on \"Phase 1\": Agreed on Monday" } ]
}
  • The tree is given by parent. Sibling order is the order of the nodes array. Parent links are drawn automatically; edges are extra links (cross references, flowchart arrows).
  • shape: rounded rect ellipse diamond parallelogram stadium hexagon cylinder sticky text.
  • color: default red orange yellow green teal blue purple pink gray.
  • settings.layout: mindmap right down radial layered-down layered-right free. In every mode but free the positions are computed automatically and x/y are overwritten; in free they are used as given.
  • settings.edgeStyle: curved straight orthogonal. An edge's own style overrides it.
  • w/h fix a node's size; null means "fit the text".
  • Unknown fields are dropped and invalid references repaired on import, so a partially correct file still loads.

Operations

An operation is an object with an op key. Lists are applied in order and atomically: if one fails, nothing changes and the error names the failing index. Each operation records a log entry with the author.

Outline format

The compact text form, used by Export ▾ Copy outline, by #outline= and by paste. It is ordinary markdown.

# Map name

- Root idea
  - First branch {color=blue}
    - Leaf with notes
      > Notes can span
      > several lines
    - Decision {shape=diamond tags=risk,todo}
  - Second branch

## Links

- Leaf with notes -> Second branch: see also
- First branch -- Second branch

## Notes

- A note on the whole map
  • Two spaces (or a tab) per level. Bullets (-, *, 1.) are optional, so tab-indented plain text also works.
  • Lines starting with > become the notes of the item above.
  • {shape=… color=… tags=a,b} at the end of a line sets node properties.
  • ## Links lists extra links by node text: -> for an arrow, -- for a plain line, : label optional.

await mindmap.createMap({ name: 'Login flow', kind: 'flowchart' });
mindmap.apply([
  { op: 'addNode', id: 'start', text: 'Start', shape: 'stadium' },
  { op: 'addNode', id: 'creds', text: 'Enter credentials', shape: 'parallelogram' },
  { op: 'addNode', id: 'ok', text: 'Valid?', shape: 'diamond', color: 'yellow' },
  { op: 'addNode', id: 'home', text: 'Show home', shape: 'rect' },
  { op: 'addNode', id: 'end', text: 'End', shape: 'stadium' },
  { op: 'addEdge', from: 'start', to: 'creds' },
  { op: 'addEdge', from: 'creds', to: 'ok' },
  { op: 'addEdge', from: 'ok', to: 'home', label: 'yes' },
  { op: 'addEdge', from: 'ok', to: 'creds', label: 'no' },
  { op: 'addEdge', from: 'home', to: 'end' },
  { op: 'layout', mode: 'layered-down', once: true },
], { author: 'claude' });
